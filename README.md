# MOSIP — ID Generator Service Setup

> Automated setup for the **MOSIP Kernel ID Generator Service** — a Vert.x + Spring Boot service that generates cryptographically secure **UINs**, **VIDs**, and **PRIDs**.

---

## What this repo contains

| File | Purpose |
|------|---------|
| `README.md` | This guide |
| `setup.ps1` | One-click setup script — clones, configures, builds, and runs the service |

---

## Prerequisites

Install these before running the script:

| Tool | Version | Download |
|------|---------|----------|
| Java (JDK) | **21** | https://adoptium.net |
| Maven | **3.6+** | https://maven.apache.org/download.cgi |
| Git | latest | https://git-scm.com |

> PostgreSQL is **not required** — the service uses an H2 in-memory database by default.

---

## How to Run

```powershell
# 1. Clone this repo
git clone https://github.com/<your-username>/<your-repo>.git
cd <your-repo>

# 2. Run the setup script
.\setup.ps1
```

That's it. The script will:
1. Clone the MOSIP `commons` source repository
2. Generate the `application-local.properties` config file
3. Build the project with Maven
4. Start the ID Generator service

## What gets configured automatically

### Service Endpoint
```
http://localhost:8080/v1/idgenerator
```

### Database (H2 in-memory — no install needed)
```
H2 Console : http://localhost:8080/h2-console
JDBC URL   : jdbc:h2:mem:mosip_kernel
Username   : kerneluser
Password   : Mosip@dev123
```

### Health & Metrics
```
http://localhost:8080/v1/idgenerator/actuator/health
http://localhost:8080/v1/idgenerator/actuator/prometheus
```

---

## API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| `GET` | `/v1/idgenerator/uin` | Fetch a pre-generated UIN |
| `GET` | `/v1/idgenerator/vid/{vidType}` | Generate VID (`PERPETUAL` / `TEMPORARY`) |
| `GET` | `/v1/idgenerator/actuator/health` | Health check |
| `GET` | `/v1/idgenerator/actuator/prometheus` | Prometheus metrics |

## Key Configuration (auto-generated by script)

### UIN
| Setting | Value |
|---------|-------|
| Length | 10 digits |
| Pool size before refill | 100,000 |
| Batch generation size | 2,000 |
| Forbidden start digits | 0, 1 |
| Restricted numbers | 786, 666 |
| Max digit sequence | 3 |

### VID
| Setting | Value |
|---------|-------|
| Length | 16 digits |
| Pool threshold | 5 |
| Batch size | 10 |
| Expiry recycle delay | 5 days |

### Auth (local mode — bypassed)
Authentication is disabled locally via the built-in `LocalNoOpAuthProvider`. No token is required to call the APIs during development.
